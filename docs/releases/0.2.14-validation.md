# 0.2.14 编辑权限发布验证

验证日期：2026-09-24。发布目标：`@deepctrls/craftjs@0.2.14`。

## 修改范围

- 默认关闭的编辑权限策略：图层位置锁、全锁、祖先锁和临时隔离范围。
- 框架 action 提交前原子校验，涵盖 props/custom、结构、setState、规范化和历史包装。
- 画布选中、悬停、整组选区拖拽和落点的实时权限检查。
- 显式文档加载、受宿主授权的运行数据/绑定更新、延迟事务修订号。
- 包内携带本次修改的 utils 运行时及声明，避免发布后依赖官方旧实现。

原 designer 项目的业务文件和依赖不在本次提交范围内。

## 验证边界与已知限制

- 没有执行 Cypress 浏览器端到端套件，也没有在原 designer 应用里替换依赖后全页面验收。Jest DOM 测试不等同于真实浏览器端到端测试。
- 原有 React 19 connector 仍会报告 `Accessing element.ref was removed in React 19`。本次新增宿主测试仅精确过滤这条已确认的基线告警，其他 `console.error` 仍导致失败。
- 几何分类默认覆盖标准 `props.style`；管道控制点等业务字段必须接入 `isGeometryProp` 扩展。
- 结构保护采用保守规则：容器含锁定后代时，改变该容器的子节点结构也会被拒绝，ROOT 同样适用。
- `document-load` 和配置变更是可信宿主能力；此机制不是针对任意 JavaScript 的安全沙箱。

这些结果提供回归证据，不代表所有应用组合都已验证或保证零缺陷。接入及迁移方式见 `scripts/logic-package.README.md`。
